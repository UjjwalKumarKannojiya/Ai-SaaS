# 🚀 FluxForge Backend (Strapi)

Welcome to **FluxForge**, the next‑generation AI‑SaaS platform. This repository hosts the backend services built with **Strapi 5**, providing a robust content management API for our AI‑driven features.

## Features
- **Real‑time content API** powered by Strapi.
- **Secure authentication** with JWT.
- **Ready for cloud deployment** – supports Strapi Cloud, Docker, and Vercel.
- **Extensible plugin system** for AI integrations.

## Getting Started
```bash
# Install dependencies
npm install
# Run development server with hot‑reload
npm run develop
```

## Deployment
Refer to the [Strapi deployment guide](https://docs.strapi.io/dev-docs/deployment) for instructions on deploying to your preferred environment (Docker, Vercel, or Strapi Cloud).
